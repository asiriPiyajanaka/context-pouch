# Webview rules

These instructions apply only to code within `media/`.

Give every interactive control an accessible name and visible keyboard focus. Provide keyboard-accessible alternatives to pointer-only graph interactions.

Escape workspace text and model-generated text before inserting it into HTML. Prefer `textContent` when markup is unnecessary.

Use VS Code theme variables for foreground, background, input, and focus colors, with sensible fallbacks. Honor reduced-motion preferences for new animations.
